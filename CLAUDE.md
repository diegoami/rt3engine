# The Claude Code mode

This file records the Claude-specific process and the project slot.

## The process

- Claude **implements** the change on a branch and opens a pull request; each
  review round is posted on it as `PRINCIPLES.md` says (*Posting*, *Pull
  requests*), which also covers a project with no remote yet.
- The review is a **fresh-context session** — a new session that has not seen
  the implementation. **The reviewer is the same model family by default; no
  cross-family reviewer is required.** The mechanism may instead be an
  **external process** from another family (for example `codex exec`, or
  `opencode run -m <provider>/<model>`); when it is, record the tool and the
  model id in the review.
- There is **no design stage**, and a change's review carries **no AGREE/BLOCK
  marker**. The review is recorded per [`reviews/README.md`](reviews/README.md).
- **Milestones** follow `PRINCIPLES.md` (*Milestones*); their verdict is not a
  change's review and does carry the marker.
- **Fallback:** a new session, or the external process, recorded. The rules
  are in the protocol.
- The builder fixes findings in the same change; a finding the builder disagrees
  with goes to the owner, not around the reviewer.
- The **owner may review** as an independent option, but an owner is not
  automatically a fresh context — and is not one if they directed or wrote
  the change.
- The **owner merges** (`PRINCIPLES.md`), unless the project slot records
  `merge: auto`. The owner may also ask for a review by OpenCode's process
  instead, when a cross-family check is wanted.

Materiality, fallback, waiver and the defect path are in `PRINCIPLES.md`;
the bootstrap applies as written there — one review, not two stages.

## Project slot

<!-- SLOT:BEGIN -->

- **product:** rt3engine — An open, native stand-in engine for Railroad Tycoon 3 that plays the original game from the user's own installation assets, with headless simulation, observers, save/map compatibility, and an MCP interface for AI-assisted play.
- **premise:** product — the project's content is the deliverable.
- **roles:** recorded before the mode; the mode is the implementer's tool's.
  - **implementer:** OpenCode, model `zai-coding-plan/glm-5.3`. The
    project works in OpenCode mode (`AGENTS.md`).
  - **reviewer of each change:** opencode/gpt-5.6-luna#high, as a subagent.
  - **reviewer of releases:** a model family that implemented none of the
    candidate; the owner picks one at each milestone (`PRINCIPLES.md`,
    *Milestones*).
- **paths to inspect:** `docs/` (mission, plan, milestones, decisions, environment, evidence, prior-art), `BACKLOG.md`, and the Rust workspace `crates/` (`rt3-kit` formats, `engine` simulation, `rt3ctl` CLI).
- **the canonical source:** this repository. `target/` is generated by cargo and is never cited or edited; `docs/evidence/` artifacts are generated by the commands named in `docs/evidence/README.md` — regenerate, never hand-edit.
- **paths to normally ignore:** `target/` (cargo build output) and `review-tmp/` (session/oracle working area, gitignored); read `Cargo.lock` only when dependencies are the task.
- **never read or echo:** secrets, signing material, one machine's paths. None are known; keep it that way and list them here when that changes. A path outside the repository is described relative to it or via `RT3_HOME`, never as one machine's absolute path. Never commit or paste original game bytes (assets, maps, saves, sounds) — see `docs/evidence/README.md`.
- **merge:** owner
- **design:** none — OpenCode mode only (`AGENTS.md`, *The two
  stages*).
- **milestones:** annotated tags `vX.Y.Z` on `main`, as
  `PRINCIPLES.md` (*Milestones*) says; the plan that holds each release's
  claims: `docs/milestones.md`.
- **the gates table:**

  | gate | command | covers | when | repeats | failure model |
  |---|---|---|---|---|---|
  | unit | `make test` | `cargo test --workspace` + install-backed evidence check (self-skips without `RT3_HOME`) | every change | 1 | deterministic tests; repeats when a flaky gate appears |
  | fmt | `make fmt` | formatting | every change | 1 | deterministic |
  | clippy | `make clippy` | lints, warnings denied | every change | 1 | deterministic |
  | CI | `.github/workflows/check.yml` | fmt, clippy and the unit gate | pull requests and `main` pushes | as CI runs | a red CI blocks the merge |

- **conventions:** English everywhere; UI text follows the original game's `RT3.lng` language when read. Comments and commits in the imperative, referencing the milestone or issue. Zero runtime dependencies at bootstrap; adding one is justified in its change. The original installation behind `RT3_HOME` is read-only, and original bytes never enter Git. Decided, not to be re-opened: `docs/decisions/0001-founding-decisions.md`. Open work lives in `BACKLOG.md` and `docs/milestones.md`.
